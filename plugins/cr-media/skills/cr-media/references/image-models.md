# 图像模型

下面的取值都在 2026-09-27 实测过：提交真实请求，核对输出的尺寸、格式和张数，编辑任务还看过图。

## 调用前要知道的三点

1. **传了不生效的参数不会报错。** 任务照样 `completed`，输出和没传一样。下表里标了「不生效」的参数就不要传；每次都要核对摘要里的 `size`、`mime` 和张数。
2. **只用表里列出的尺寸和比例。** 有几个模型遇到不支持的值时，任务不会失败，而是一直停在 `processing`；其中还有看起来正常的写法，比如 wan2.7-image-pro 的 `1536x1024`。`cr-image` 默认等 600 秒就超时退出。
3. **编辑后要打开图看。** gemini-3-pro-image-preview 有过任务成功、但没有照指令编辑的情况。

## 怎么选

| 需要 | 用 |
|---|---|
| 指定像素尺寸 | GPT 系三个（最大测过 2048×2048）、doubao-seedream-5.0-pro、qwen-image-3.0-pro：`--size 1536x1024` |
| 指定比例 | nano-banana-beta、两个 gemini-3.1、gemini-3-pro-image 和 -preview、doubao-seedream-5.0-pro、qwen-image-3.0-pro。GPT 系、wan2.7-image-pro、doubao-seedream-5-0-260128 的比例不生效 |
| 2K | gemini-3-pro-image（`--size 2K` → 2816×1536）；seedream 两个、qwen-image-3.0-pro、wan2.7-image-pro（`--size 2K` → 2048×2048） |
| 4K | gemini-3.1-flash-image：`--size 4K` → 5632×3072 |
| 一次出多张 | GPT 系三个、wan2.7-image-pro：`--n` |
| JPEG | GPT 系三个：`--format jpeg`。gemini-3.1-flash-image、两个 seedream 本来就出 JPEG |
| WebP | 只有 gpt-image-2 |
| 编辑图片 | nano-banana-beta、gpt-image-2、gemini-3-pro-image、qwen-image-3.0-pro、wan2.7-image-pro、两个 seedream；GPT 另外两个和两个 gemini-3.1 也能用。不要用 gemini-3-pro-image-preview |
| 最快 | doubao-seedream-5-0-260128（15 秒左右，但只出 2048×2048） |

## GPT 系：gpt-image-2.5-sunburst、gpt-image-2.5-flare、gpt-image-2

三个模型的用法相同，不同的地方单独标出来。

| 参数 | 用法 |
|---|---|
| `--size` | 像素写法：`1024x1024`、`1536x1024`、`1024x1536`、`2048x2048`。`auto` 等于不传 |
| `--aspect-ratio` | **不生效**，用 `--size` 控制形状 |
| `--quality` | `low`、`high` 能用，画质差别没有比较过 |
| `--n` | 有效，测过 9 张 |
| `--format` | `jpeg` 都能用；`webp` 只有 gpt-image-2 能用，另外两个会失败 |
| `--image` | 编辑有效。输出比例跟着输入图，但尺寸会变：1280×720 输入 → 1672×941 |

默认尺寸：flare 和 gpt-image-2 是 1254×1254 PNG；sunburst 每次都不一样，见过 1312×1199 和 1370×1148。需要固定尺寸时一定传 `--size`。

## doubao-seedream-5.0-pro

| 参数 | 用法 |
|---|---|
| `--size` | 像素写法 `1536x1024` 照办；`2K` → 2048×2048 |
| `--aspect-ratio` | `16:9` → 1424×800。不支持的比例会失败（`unsupported_capability`） |
| `--n` | 不支持，会失败 |
| `--image` | 编辑有效，输出 1424×800（1280×720 输入） |

默认 1152×864 JPEG。

## doubao-seedream-5-0-260128

| 参数 | 用法 |
|---|---|
| `--size` | 只有 `2K`（→ 2048×2048）；`1536x1024` 会失败 |
| `--aspect-ratio` | **不生效**，总是 2048×2048 |
| `--n` | **不生效**，只出 1 张 |
| `--image` | 编辑有效，输出 2048×2048 |

默认 2048×2048 JPEG。

## qwen-image-3.0-pro

| 参数 | 用法 |
|---|---|
| `--size` | 像素写法 `1536x1024` 照办；`2K` → 2048×2048 |
| `--aspect-ratio` | `16:9` → 1424×800。不支持的比例会失败（`unsupported_capability`） |
| `--n` | **不生效**，只出 1 张 |
| `--image` | 编辑有效，输出 2720×1536（1280×720 输入） |

默认 2048×2048 PNG。

## wan2.7-image-pro

| 参数 | 用法 |
|---|---|
| `--size` | 只用 `2K`（→ 2048×2048）。**`1536x1024` 会让任务一直挂着**，不要用 |
| `--aspect-ratio` | **不生效**，总是 2048×2048 |
| `--n` | 有效，测过 2 张 |
| `--image` | 编辑有效，输出 2730×1536（1280×720 输入） |

默认 2048×2048 PNG。偶尔返回 `upstream_rate_limited`，过一会儿重试就好。

## nano-banana-beta

| 参数 | 用法 |
|---|---|
| `--aspect-ratio` | 16:9 → 1344×768，9:16 → 768×1344，4:3 → 1184×864，3:2 → 1248×832，21:9 → 1536×672 |
| `--size` | 只有 `1024x1024` 或 `1K`（→ 1024×1024）。`2K`、`4K` **不生效** |
| `--n` | 不支持，会失败 |
| `--format` | 不支持，会失败。只出 PNG |
| `--image` | 编辑有效，URL 和本地文件都能用。输出尺寸不跟随输入图，而是取最接近的比例档位：1280×720 输入 → 1344×768，512×512 输入 → 1024×1024 |

默认 1024×1024 PNG。

编辑时可能连带改动别的地方：让它「只把杯子改成红色」，它连杯子的形状也换了（三次改色里有一次）。

## gemini-3.1-flash-image

| 参数 | 用法 |
|---|---|
| `--size` | 档位写法：`1K` → 1408×768，`2K` → 2816×1536，`4K` → 5632×3072。`1024x1024` 也能用 |
| `--aspect-ratio` | 16:9 → 1376×768，9:16 → 768×1376，4:3 → 1200×896，3:2 → 1264×848，21:9 → 1584×672。和 `--size` 一起用没测过 |
| `--n` | 不支持，会失败 |
| `--format` | 不支持，会失败。只出 JPEG |
| `--image` | 编辑有效。尺寸不跟随输入：1280×720 输入 → 1365×768 |

默认 1408×768 JPEG。

## gemini-3.1-flash-lite-image

| 参数 | 用法 |
|---|---|
| `--size` | **不要传**：`2K` 会让任务一直挂着（这个写法在 gemini-3.1-flash-image 上是可以的），`1536x1024` 会失败 |
| `--aspect-ratio` | `16:9` → 1376×768 |
| `--n` | 不支持，会失败 |
| `--image` | 编辑有效，输出 1365×768 |

默认 1408×768 JPEG。会自己往画面里加提示词没提的东西（让它画杯子，杯里多了咖啡）。

## gemini-3-pro-image

正式版，和下面的 preview 版行为不同。

| 参数 | 用法 |
|---|---|
| `--size` | `2K` → 2816×1536；`1536x1024` 会失败 |
| `--aspect-ratio` | `16:9` → 1376×768 |
| `--n` | 不支持，会失败 |
| `--image` | 编辑有效，照办了，输出 1365×768 |

默认 1408×768 JPEG。

## gemini-3-pro-image-preview

| 参数 | 用法 |
|---|---|
| `--size` | **不要传**，任何写法都会失败。输出固定在 2K 左右 |
| `--aspect-ratio` | 16:9 → 2752×1536，9:16 → 1536×2752，4:3 → 2400×1792，3:2 → 2528×1696，21:9 → 3168×1344 |
| `--n` | **不生效**，只出 1 张 |
| `--format` | **不生效**，只出 PNG |
| `--image` | **不要用**：测试中任务成功了，但图没有照指令编辑。要编辑就用 gemini-3-pro-image |

默认 2816×1536 PNG。

## 没测过

`--mask` 局部编辑、多张输入图、`negative_prompt`、`seed`、`response_format`、`callback_url`；新加的六个模型的 `--quality`、`--format`，以及除 16:9 以外的比例。用了要跟用户说明是在试，并核对输出。
